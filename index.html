    🍽️ Savor - Advanced Recipe Finder

    Discover real recipes, save favorites, plan your week, and turn meal ideas into a ready shopping list.

    📖 What It Does

    Savor is a polished recipe discovery app powered by TheMealDB. It helps users search meals by name, browse cuisines and categories, open detailed recipes, save favorites, rate dishes, write personal notes, plan meals, and prepare shopping lists.

    🎮 How to Use

    • Search for recipes like pasta, curry, tacos, or cake
    • Use cuisine and category chips to browse curated results
    • Add ingredients and search for matching recipes
    • Open any recipe to view ingredients and instructions
    • Save recipes, add ratings, and write personal notes
    • Add recipes to the weekly planner and generate shopping items
    • Use cooking mode for step-by-step kitchen guidance
    • Switch between grid/list views and toggle dark mode

    ✨ Key Features

    • Recipe Search: Live recipe lookup through TheMealDB API
    • Smart Browsing: Cuisine, category, and ingredient-based discovery
    • Detailed Modal: Recipe image, stats, ingredients, instructions, source links, and videos
    • Saved Collection: Favorites, ratings, and notes stored with localStorage
    • Meal Planner: Weekly planning across breakfast, lunch, dinner, and snacks
    • Shopping List: Generate ingredients from the meal plan and check them off
    • Cooking Mode: Step-by-step view with timer support
    • Responsive UI: Desktop and mobile layouts with light/dark theme support

    🚀 Key JavaScript Concepts

    • Async Fetch: API calls for search, filters, lookup, categories, and random meals
    • State Management: Central state object for recipes, filters, favorites, notes, planner, and shopping list
    • DOM Rendering: Dynamic cards, modals, panels, planner grid, and shopping rows
    • localStorage: Persistent theme, favorites, notes, ratings, shopping list, and meal plan
    • Drag & Drop: Recipe planning workflow through draggable cards
    • IntersectionObserver: Infinite-style result pagination
    • Timers: Cooking mode timer using interval controls
    • Error Handling: User-facing toasts and graceful empty states

    🎨 Design Features

    • Editorial recipe-inspired typography and warm color palette
    • Sticky header with compact action buttons
    • Responsive recipe cards with image-forward presentation
    • Modal and side-panel workflows for focused cooking tasks
    • Animated loaders, toasts, and hover interactions
    • Dark mode support through CSS custom properties

    💻 Technologies Used
